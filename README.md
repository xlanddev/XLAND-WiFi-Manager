# 📶 XLAND WiFi Manager

**A Modern Wi-Fi and Network Monitoring Application**

XLAND WiFi Manager is a desktop application designed to manage, monitor, and analyze Wi-Fi connections and network performance. It is developed using Python and PyQt6.

The goal of this project is to provide a simple, modern, and user-friendly dashboard for monitoring network connectivity and connection quality.

## ✨ Features

- 📡 Wi-Fi network management and monitoring
- 📊 Real-time network traffic monitoring (Download / Upload)
- 📶 Internet connection quality monitoring
- ⏱️ Network latency monitoring (Ping)
- 📉 Packet loss calculation
- 🖥️ Modern user interface with a Black & Neon Green theme
- 🐧 Linux support
- 🪟 Windows support

1. Download the Windows ZIP package.
2. Extract the ZIP archive.
3. Open the extracted application folder.
4. Run `XLAND-WiFi-Manager.exe`.
5. If required, run the application as Administrator.

### Linux Installation

1. Download the Linux ZIP package.
2. Extract the ZIP archive.
3. Open the extracted application folder.
4. Open a terminal in that directory.
5. Run the following commands:

```bash
chmod +x XLAND-WiFi-Manager
./XLAND-WiFi-Manager
```

## 📖 User Guide

### 1. Main Dashboard

After launching the application, the main dashboard provides an overview of your network information and connection status.

### 2. Network Traffic Monitoring

The Network Traffic section displays real-time download and upload traffic for the selected network interface.

### 3. Ping Monitor

The Ping Monitor measures network latency by sending requests to a remote server.

### 4. Packet Loss Monitor

The Packet Loss section calculates the percentage of lost packets based on recent network test samples.

### 5. Connection Quality

The application evaluates connection quality based on network monitoring results.

**Note:** Network traffic measurements belong to the selected network interface and may include local network traffic. Ping results represent the connection path to the configured test destination and do not necessarily reflect the quality of the entire internet connection.
